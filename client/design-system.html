"Golden Hour Gathering" — every token and component on this page is rendered from the app's real stylesheet, not redrawn. See DESIGN.md at the repo root for the full rationale.

Color

Dominant warm terracotta on cream, with olive as the sole confirmation accent and a restrained semantic set for warn/danger. Values are read live via getComputedStyle — the labels below cannot drift from the CSS.

Type

Display: Fraunces (italic, optical sizing) for warmth and editorial character. Body: Nunito, rounded and friendly, carried over from the app's original identity. Full scale below, each row using the real class/element.

Spacing & radius

4px-based spacing scale; radius scale from tight controls up to the pill shape used for tags and progress bars.

Shadow & motion

Shadows are warm-tinted (never pure black) to sit on the cream ground. Motion uses a standard ease for fades/borders and a slight-overshoot "press" ease for anything tactile — hover the tiles to feel each one; respects prefers-reduced-motion.

Background & texture

A near-invisible warm noise texture (SVG feTurbulence, inlined as a data URI in body) keeps the cream ground from feeling flat, without adding any image weight. Sampled here at higher opacity so it reads on screen.
